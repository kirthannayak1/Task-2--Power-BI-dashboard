Superstore Sales & Profit Analytics
An interactive Power BI dashboard built using the Superstore dataset to analyze sales, profit, orders, product categories, sub-categories, and regional performance. The project uses DAX measures and interactive visualizations to identify trends, compare business performance, and present meaningful insights through data storytelling.

Dashboard Description
An interactive Power BI dashboard featuring key KPIs such as Total Sales, Total Profit, Total Orders, Total Quantity, and Profit Margin. The dashboard uses Line, Column, Bar, Pie, Gauge, and Map charts to visualize sales and profit trends, category and regional performance, sales distribution, top sub-categories, profitability, and geographical sales performance.
